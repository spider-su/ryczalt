# Rental MVP scope

- Single main income screen; property name, default rent, current tenant name/phone/email.
- Only manually confirmed received payments count as taxable income. Preserve tenant name snapshot with payment.
- Manually confirmed tax payments; annual PIT-28-oriented summary after tax rules are implemented and tested.
- Local versioned JSON document; optional manual export/import, then Investory generic JSON backup.
- No bank integration, automatic payments, tenant contract lifecycle, valuation, yield, or retirement features.
- Source: ryczalt_it/develop Expo mobile stack and selected Investory long-term rental domain ideas, not its backend.
